The Problem With Traditional Batch Resizers

Most "batch resize" tools online share a broken workflow:

  1. Upload to the cloud — your photos sit on their server, even if briefly.
  2. One size per run — even though they call it "batch," you still have to re-upload, re-set sizes, and download for every dimension you need.
  3. Extra steps for HEIC — iPhone photos come in HEIC; these tools can't handle them, so you convert first, then batch resize.
  4. Subscription pricing — the tool is free, but "premium" features (custom sizes, better compression, no watermark) require a monthly subscription.

For a task as simple as "resize a folder of photos," this feels backwards.

Padding vs. Cropping vs. Stretch

When you resize a batch of photos to a specific dimension, you often run into aspect ratio mismatches. A portrait photo resized to a landscape size needs to go somewhere.

A good tool gives you three options:

  • Pad — add a solid or gradient background to fit the size without distorting the image.
  • Crop — trim the image to fill the size edge-to-edge.
  • Stretch — (avoid; distorts the photo).

Each mode is useful for different contexts (social media prefers padding; thumbnails prefer crop). A flexible tool lets you pick the mode per size, so you can pad for Instagram, crop for web thumbnails, and stretch for neither.

Format Conversion: HEIC → JPG, PNG, WebP

Beyond resizing, format conversion is crucial:

  • JPG — best for photographs and complex images; good compression, widely supported.
  • PNG — best for graphics and images with transparency; lossless, larger file size.
  • WebP — modern, smaller file sizes, increasingly browser support; great for web.
  • HEIC — Apple's format; excellent compression, but poor web support (only Safari).

If you're batching images from your iPhone for the web, you're converting HEIC to JPG or WebP. A tool that handles this as part of the resize pipeline saves you at least one extra app/step.
